RC Circuits: charging, steady state, and opening the switch

A capacitor behaves differently at different moments: like a wire when it is empty, like a gap when it is full, and like a battery when it is charged and the source is removed. Use the lab below to see the total current and every potential difference as time passes. Predict first, then check.

2 · The physics in four moves

Move 1: the capacitor rule

VC = q / C     IC = dq/dt

The voltage across a capacitor cannot jump, because that would need infinite current. So at the instant something changes, VC is whatever it was just before. An empty capacitor (VC = 0) acts like a wire at that instant. After a long time the current dies out and it acts like a gap (open circuit).

Move 2: series RC, switch closed (Kirchhoff loop rule)

ε − IR − q/C = 0,   I = dq/dt  ⟹  q(t) = Cε(1 − e−t/τ),   τ = RC
I(t) = (ε/R) e−t/τ    VR(t) = ε e−t/τ    VC(t) = ε (1 − e−t/τ)

Check the limits: t = 0 gives I = ε/R and VC = 0. As t → ∞, I → 0 and VC → ε.

Move 3: add a resistor R₂ in parallel with C (the "total current" version)

R₁ is in series with the parallel pair (R₂ ∥ C). R₂ and C share the same voltage VC, and the total current splits at the junction:

Itotal = (ε − VC)/R₁ = VC/R₂ + C dVC/dt

This is a series RC circuit whose battery is replaced by its Thevenin equivalent:

V∞ = ε R₂/(R₁+R₂)    Rth = R₁R₂/(R₁+R₂)    τ = RthC    VC(t) = V∞(1 − e−t/τ)
t = 0⁺: Itotal = ε/R₁ (C shorts R₂)   →   t → ∞: Itotal = ε/(R₁+R₂)

Move 4: open the switch

With no R₂, the charge has nowhere to go, so VC stays put (an ideal capacitor). With R₂, the capacitor discharges through it:

VC(t) = V₀ e−t/(R₂C)    IR₂ = VC/R₂    Itotal = 0

Notice the capacitor current reverses (IC goes negative). It is now the source.

Energy bookkeeping (series RC)

The battery supplies Cε² in total, since ∫ε I dt = ε·qfinal = Cε². The capacitor stores only ½Cε². The other ½Cε² is dissipated as heat in R, no matter what R is. Check this with the lab: the stored-energy readout levels off at half of what the battery has delivered.
